Research Projects

Projects

NeuroTIA Transformer [Link]

NeuroTIA is an EEG motor-imagery classification project that uses a compact CNN–Transformer model to classify imagined left- and right-hand movement. It includes model comparisons, a results dashboard, and a LangGraph workflow for checking and explaining project evidence with a local LLM.

  • Built the EEG preprocessing pipeline, including filtering, epoching, and Riemannian alignment.
  • Implemented signed temporal-energy attention and compared it with standard-attention and generic-energy controls.
  • Evaluated the model at 89.32% accuracy on one 31-participant validation fold; the standard-attention control scored 89.61%.
  • Developed a results dashboard and a LangGraph workflow for evidence checks and result reporting.

Technology Stack: Python, PyTorch, LangGraph, Ollama, HTML, CSS, JavaScript, Node.js

ResearchOS [Link]

ResearchOS is an AI-assisted research framework for scholarly literature analysis, hypothesis development, evidence verifi- cation, and academic document preparation.
